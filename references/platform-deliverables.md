# Platform Deliverables and Character Targets

This file defines the default copy-bank quantities used by the Paid Ads Copywriting Skill. These quantities are the Skill's working defaults, not universal platform-mandated counts. Platform formats and specifications can change, so verify official documentation when exact current compliance is required.

## Google Performance Max
- 15 headlines, max 30 characters each
- 5 long headlines, max 90 characters each
- 5 descriptions, max 90 characters each

## Google Search / Responsive Search Ads
- Up to 15 headlines, max 30 characters each
- Up to 4 descriptions per RSA, max 90 characters each
- Skill default: 15 headlines + 4 descriptions. If the user requests 5 descriptions, provide a fifth as an extra copy-bank option, clearly noting that one RSA accepts up to four description assets.

## Meta (Facebook / Instagram), feed-style copy bank
- 3 primary text versions: short, medium, offer-led (adapt if the brief calls for another strategic split)
- 3 headlines
- 3 descriptions
- 3 in-creative hooks if overlay text is needed or requested
- Working targets: primary text front-loads the key idea within the first ~125 characters; headline ≤40 characters; description ≤30 characters. These are writing targets and may vary by placement/ad format, not universal hard limits.

## Reddit, feed-style copy bank
- 5 headline options; target ≤100 characters, preferably ≤80 if truncation is a concern
- 3 body-copy versions
- 3 optional creative overlay/caption lines if image/video creative is used
- Reddit Free-form ad supports one headline and rich body text per ad. Variations are a copy bank for testing, not fields to combine into one ad.

## TikTok, paid video-first copy bank
- 5 opening hooks
- 3 primary ad-text versions
- 3 CTA options when CTA testing is relevant
- Add a script or shot-by-shot structure only if requested or clearly needed.

## YouTube
- Ask for the ad format when the user has not specified it and format affects copy requirements.
- Working copy bank for a general video ad request: 5 opening hooks, 5 headlines, 5 descriptions. Confirm and adapt to the selected format; do not present these quantities as universal platform requirements.

## Other platforms or formats
For LinkedIn, Pinterest, X, Amazon Ads, The Trade Desk, Google Display, Demand Gen, YouTube Shorts, or other formats, identify the exact ad type if relevant. If the Skill has no verified default, ask whether the user wants a practical copy bank or wants current official field specifications checked. Do not invent a hard platform limit.

## Official specification references reviewed when this file was created
- Google Ads Help, Responsive Search Ads: https://support.google.com/google-ads/answer/7684791
  - RSA headlines: 3–15 assets, up to 30 characters each; descriptions: 2–4 assets, up to 90 characters each.
- Google Ads API, Responsive Search Ads overview: https://developers.google.com/google-ads/api/docs/responsive-search-ads/overview
- Reddit Ads Help, Creative Best Practices: https://business.reddithelp.com/articles/Knowledge/Creative-Best-Practices
  - Reddit recommends short, engaging headlines, typically no more than 150 characters.
- Reddit Ads Help, Ad Unit Specifications: https://business.reddithelp.com/articles/Knowledge/Reddit-Ad-Unit-Specifications
  - Reddit recommends limiting headlines to 100 characters, or 80 characters if truncation is a concern.
- Reddit Ads Help, Free-form Ad Specifications: https://business.reddithelp.com/s/article/free-form-ad-specifications
  - Free-form format has one headline and rich body text per ad.

Meta working targets in this file are practical copywriting defaults, not claims that one universal set of character limits applies to all placements. Check the current Meta Ads Guide for the exact placement and format when strict platform compliance is needed.
