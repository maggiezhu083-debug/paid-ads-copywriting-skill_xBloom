# Paid Ads Copywriting Skill

## Contents
- `SKILL.md`: the main skill instructions.
- `references/platform-deliverables.md`: default copy counts, working character targets, and official specification references.
- `references/xbloom_paid_ads_copywriting_guidelines.md`: supplied xBloom paid ads guide.
- `references/xbloom_anti_ai_copy_check.md`: supplied xBloom anti-AI copy checklist.

## Important
The detailed xBloom voice rules are conditional and should only be applied to xBloom work. For other brands, the skill uses the general principles of specificity, clarity, distinct creative angles, accurate claims, and natural language.

## Example interaction
User: “I need Google copy for xBloom Studio.”

Expected skill behavior:
1. Recognize Google Performance Max as the default because the user has not named Search/RSA.
2. Ask the user to choose or approve a style and tone before drafting.
3. After approval, produce 15 headlines (≤30 characters), 5 long headlines (≤90 characters), and 5 descriptions (≤90 characters).
4. Count each asset, fix over-limit copy, and present the final character counts.

User: “Write Meta ads, style UGC, tone witty and conversational.”
Expected behavior: show a concise direction summary and request confirmation; after confirmation, produce 3 primary texts, 3 headlines, 3 descriptions, plus 3 creative hooks when relevant.

## Installation
Upload/import the folder or ZIP into a product that supports custom Skills. If your product only accepts a single instruction field, paste the content of `SKILL.md` into that field and upload the reference files separately if supported.
